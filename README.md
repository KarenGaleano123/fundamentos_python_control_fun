# Fundamentos de Python - Estructuras de Control y Funciones

## Descripción

Este repositorio contiene los ejercicios desarrollados durante el estudio de los fundamentos de Python, enfocados en estructuras condicionales, estructuras iterativas y funciones.

El objetivo es fortalecer las habilidades de programación mediante la resolución de ejercicios prácticos que permiten comprender la lógica de programación y el uso de las principales estructuras del lenguaje Python.

# Requisitos

Para ejecutar los ejercicios es necesario tener instalado:

- Python 3.x
- Visual Studio Code, PyCharm o cualquier editor de código

Verificar la instalación:

```bash
python --version
```

o

```bash
python3 --version
```

---

# Cómo Ejecutar los Ejercicios

## Abrir una Terminal

Ubicarse en la carpeta principal del proyecto:

```bash
cd fundamentos_python_control_fun
```

---

# Ejercicios de Condicionales

Ingresar a la carpeta:

```bash
cd src/condicionales
```

Ejecutar cualquier ejercicio:

```bash
python nombre_del_archivo.py
```

Ejemplos:

```bash
python edad_if.py
python edad_if_else.py
python edad_if_elif_else.py
python Operador_and.py
python Operador_or.py
python Operador_not.py
python contraseña_if_else.py
```

---

# Ejercicios de Funciones

Ingresar a la carpeta:
